# Individual Reflection
## Missing Transaction Ownership Verification in Refunds
I realised that verifying whether a transaction exists is not enough to approve a refund. It is equally important to confirm that the transaction belongs to the customer requesting the refund. 
I learned that missing ownership verification could allow one customer to use another customer's transaction reference to obtain an unauthorised refund. 
This exercise strengthened my understanding of transaction integrity, customer data protection, and the importance of proper authorization checks in financial systems. I also learned that security testing should focus not only on whether a process works but also on whether it works securely.
